# Personal Wiki Build Pack

> Historical note: this pack was delivered as a ZIP. Its files now live at the
> repository root (`START_HERE_PROMPT.md`, `PERSONAL_WIKI_MASTER_GUIDE.md`,
> `CLAUDE.md`, `references/`), plus `docs/UI_SPEC.md`. See the root `README.md`.

Use this pack as the design and implementation contract for building Personal Wiki.

## Start

1. Open `START_HERE_PROMPT.md` and send its contents to the coding agent.
2. Attach this entire folder/ZIP to the agent if supported.
3. The agent must read `PERSONAL_WIKI_MASTER_GUIDE.md`.
4. The images in `references/` are the visual source of truth.

`CLAUDE.md` is included so Claude Code can automatically load the core project rules when this pack is placed in the repository root.

## Files

- `START_HERE_PROMPT.md` — one-shot implementation prompt.
- `PERSONAL_WIKI_MASTER_GUIDE.md` — full architecture/product guide.
- `CLAUDE.md` — compact persistent project instructions for Claude Code.
- `references/` — UI reference images.
